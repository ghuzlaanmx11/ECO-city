# ECO CITY — المدينة المستقبلية المستدامة

تجربة عربية تفاعلية لمدينة مستقبلية مبنية بمشهد WebGL حقيقي باستخدام Three.js. لا يتطلب المشروع خطوة بناء أو تثبيت حزم؛ تُحمّل Three.js وOrbitControls وخطوط الواجهة من CDN، لذلك يلزم اتصال بالإنترنت عند فتح الصفحة.

## التشغيل

انشر محتويات المجلد على GitHub Pages من إعدادات المستودع، أو شغّل `index.html` عبر خادم ملفات ثابت محلي. استخدام خادم محلي مهم لتحميل وحدات JavaScript في بعض المتصفحات.

تستخدم روابط الملفات المحلية مسارات نسبية لتعمل مع مسار المستودع على GitHub Pages. عند تحديث ملفات CSS أو JavaScript، غيّر قيمة `v` في روابطهما داخل `index.html` لكسر التخزين المؤقت للنسخ القديمة. قد يحتفظ GitHub Pages بالملفات مؤقتًا لنحو 10 دقائق؛ بعد النشر يمكن إجراء تحديث قسري للصفحة (`Ctrl+Shift+R`). يجب أيضًا السماح بالاتصال بـ jsDelivr لتحميل Three.js وOrbitControls.

## التفاعل

- يبدأ مشهد المدينة ثلاثي الأبعاد تلقائيًا؛ لا حاجة إلى الضغط على زر أو فتح أدوات المطورين.
- اسحب المشهد لتدوير الكاميرا، واستخدم عجلة الفأرة للتقريب والتبعيد.
- انقر على المباني والعناصر لعرض بطاقاتها التعليمية.
- غيّر الوقت والطقس من لوحة التحكم.
- اختر إضافة شجرة أو لوح شمسي أو توربين، ثم انقر على موضعه في المدينة.
- طوّر الحدائق أو عدّل نسبة النقل الكهربائي لمشاهدة تغيّر المؤشرات البيئية.
